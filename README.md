# Overview
This is a final project for Introduction to Deep Learning and NLP at University of Bonn in spring 2023. The main notebook is *headline.ipynb*, which imports functions from *functions.py*. The pdf file *summary.pdf* summarizes the results and compares the performance of different approaches.

The project uses the [News Headlines Dataset for Sarcasm Detection](https://www.kaggle.com/datasets/rmisra/news-headlines-dataset-for-sarcasm-detection), which has 26,709 headlines: about 56.1% are non-sarcastic and 43.9% are sarcastic. The data is shuffled and split into training, validation and test sets in a 0.7 : 0.15 : 0.15 ratio. I compare three approaches, and the first two both build on the pretrained model *MiniLM-L12-H384-uncased*:
+ **Feature extraction:** I try three ways of post-processing the hidden states (averaging over the token dimension, keeping the first token, keeping the last valid token). For each one, I tune a Logistic Regression and a Random Forest classifier, which gives six combinations.
+ **Fine-tuning:** I do full fine-tuning with class weights in the loss to handle the slight class imbalance. I also do parameter-efficient fine-tuning with PEFT and LoRA, where about 44% of the parameters are trainable.
+ **An existing fine-tuned model from Hugging Face:** *jkhan447/sarcasm-detection-RoBerta-base-CR*.

Full fine-tuning performs best, with a macro F1-score of 0.92 (accuracy 0.93). PEFT/LoRA is almost as good, with an F1-score of 0.92 (accuracy 0.92), even though it trains far fewer parameters. Among the feature extraction models, averaging over the token dimension with Logistic Regression does best, with an F1-score of 0.88. The Hugging Face model only scores 0.50 on this dataset.

2. What is the fundamental difference between econometrics/statistics and suprevised machine learning
   + Econometrics estimates fundamentally unobservable parameters and testing hypotheses about them, while supervised machine learning predicts observable things.
   + Supervised machine learning make use of out of sample testing to validate models so that we can evaluate how well it works, but we can't test how well econometric models work. 
   + Econometric models often rely on assumptions about the underlying economic relationships and data distribution, which need to be justified.  Supervised machine learning generally do not rely on specific assumptions about the underlying data distribution. It learns patterns directly from the data through experimentation and evaluation.
3. Can you use stochastic gradient descent to tune the hyperparameters of a random forrest. If not, why?
    + SGD is not applicable for tuning Random Forest hyperparameters.
    + SGD is designed for optimization problems with differentiable loss functions and continuous parameters, but Random forests have discrete hyperparameters (e.g. tree depth, number of trees, etc.).
    + To tune the hyperparameters of Random Forest, it's common to use techniques like Grid Search.
4. What is imbalanced data and why can it be a problem in machine learning?
    + Imbalanced data refers to a dataset in which one class of outcomes occurs more frequently that the others. 
    + When the majority outcome dominates the dataset, even a naive model that predicts only the majority outcome can achieve high accuracy. However, this model doesn't learn anything and is not useful in practice due to a lack of generalization for the underrepresented outcomes.
    + To address this issue, we need scores generated by different aggregation strategies to gain a more informative evaluation of model performance on imbalanced data.
5. Why are samples split into training and test data in machine learning?
    + By splitting the dataset into training and test data, we can assess the performance of the model. To be specific, since fitting and experimentation is only done on training data and evaluation is only done on test data, overfitting can be detected through model evaluation. And with holdout samples, we also prevent data leakage, which may lead to an over-optimistic model evaluation.
6. Describe the pros and cons of word and character level tokenization.
    + Word level tokenization
      + Pros
        + The word structure is preserved.
        + There are not too many words so the vocabulary isn't too large.
        + It is simple.
      + Cons
        + In general, it struggles with handling words not present in the pre-defined vocabulary. 
          + It might not effectively deal with word variations like "huuuuge".
          + It is sensitive to typos and misspellings.
          + It might not effectively deal with morphology.
          + It may result in incompleteness.
    + Character level tokenization
      + Pros
        + It can handle out-of-vocabulary words. Since individual characters are tokenized, there are no unknown words.
        + It results in a even smaller vocabulary compared to word level tokenization.
        + It is also simple.
      + Cons
        + The word structure is not preserved.
        + The tokenized texts are longer.
7. Why does fine-tuning usually give you a better performing model than feature extraction?
   + Because fine-tuning jointly trains both the newly-added classifier layers and the other layers of the model, allowing all parameters to be adapted and updated to the specific task at hand, while feature extraction only trains the new classification head added on top of the pretrained model.
8. What are advantages over feature extraction over fine-tuning
    + Feature extraction can be implemented with CPU, while fine-tuning will be very slow without GPU.
    + The classifier can anything in feature extraction, while it should be a differentiable neural network in fine-tuning.
    + Feature extraction usually requires less labeled data for the target task compared to fine-tuning.
9. Why are neural networks trained on GPUs or other specialized hardware?
    + Neural networks involve lot of mathematical operations like matrix multiplication, which can be parallelized. GPUs (or other specialized harware) are designed to handle parallel processing efficiently and also have high memory bandwidth, which reduces the time required for training neural networks.

13. Some would say that softmax is a bad name. What would be a better name and why?
    + A better name would be soft argmax.
    + Softmax converts any real-valued vector into a vector of valid probabilities, where the output values sum up to 1, with higher values representing higher probabilities. It approximates an argmax in the following sense: If sizes of vector elements vary strongly, it becomes an indicator function for the largest element.

18. Why can the feed-forward neural network we implemented for image classification not be used for language modelling?
    + Feed-forward neural networks are designed for fixed-size model inputs, but can't process input sequences of different lengths in language modelling.
    + Feed-forward neural networks have no memory between inputs.
19. Why is an encoder-decoder architecture used for machine translation (instead of the simpler encoder only architecture we used for language modelling)
    + The encoder-decoder architecture is more efficient in handling input and target sentence which might have different lengths, or in which order of words might be different.

22. What is an example of an encoder-only model?

23. What is the vanishing gradient problem and how does it affect training?
    +  It refers to an issue that arises in the training of RNNs: the gradients of the loss function with respect to the parameters can become extremely small due to repeated multiplication with $W_{hh}$ and back-propagation. 
    +  In this case, the weights of the lower layers (closer to the input) are updated very little, the learning process can become very slow, and it may take a long time to train the network effectively.
24. Which model has a longer memory: RNN or Transformer?
    + Transformers have longer memory.
    + In RNNs hidden state $h_t$ is the only thing that has memory, while in Transformers the attention calculate different weighted averages of input vector. So Transformers are able to capture connections across long distances in the input sequence more effectively.
25. What is the fundamental component of the transformer architecture?
    + It's self-attention. Self-attention enables Transformers to model connections between different input vectors in the input sequence by computing a weighted sum of the embeddings of all positions, where the weights represent the importance of each position.
